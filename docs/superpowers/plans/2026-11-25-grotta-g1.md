# Grotta: G1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Man kan gå inn i grotta fra skogkanten, gå ned trapp for trapp i etasjer fra generatoren, og komme hjem igjen. Etter etasje 5 og 10 kan man ta tauet ned dit. Alt ligger bak `FEATURES.cave`. Ingen monstre og ingen kamp; det er G2.

**Architecture:**
- En egen Phaser-scene, `CaveScene`, tegner én `Floor` om gangen. Bygda legges i dvale (`scene.sleep`) mens man er nede, og vekkes igjen (`scene.wake`).
- React eier tilstanden og snakker med scenene gjennom `bridge.ts`, som i dag: HUD sender `enterCave`, `descend` og `leaveCave`, og scenen svarer med `reachedFloor` og `leftCave`.
- Bevegelse, kollisjon og figur-tekstur trekkes ut av `WinterQuestScene` til små, delte moduler, så de to scenene ikke kopierer kode.

**Tech Stack:** Phaser 4.2.1, React 19 / Next 16, TypeScript, `node --test` med `sucrase`.

**Spec:**
- `docs/plan-grotta.md`, del 4 («Inngangen», «Én scene for grotta», «Hva som skjer når») og del 7 («Kalenderen går foran»);
- `docs/superpowers/plans/2026-11-25-grotta-fase-a-g0.md`, «Til G1-planen».

## Global Constraints

- Med `FEATURES.cave` av er bygda nøyaktig som før: ingen ny sti, ingen inngang, ingen nye trær borte og ingen grotteark lastet.
- `FEATURES.cave` (`NEXT_PUBLIC_FEATURE_CAVE === "1"`) slår også på `FEATURES.rpg`.
- Bare Kenney-grafikk som allerede ligger i repoet. Ingen nedlasting og ingen nye npm-avhengigheter.
- Nye felt i `Progress` legges bare til og vaskes i `readProgress`.
- Overgangen inn, ned og hjem er en toning på under et halvt sekund (200 ms ut og 200 ms inn).
- En luke tar deg alltid hjem: «Gå til …» fra sporingen, journalen eller kartet mens du er i grotta, går først hjem og deretter dit.
- Lukk paneler og samtaler (`frozen`) stopper bevegelse i grotta, som i bygda.
- Norsk tekst i UI, i vanlige ord. Prompter: «<kbd>E</kbd> Gå inn i grotta», «Tau ned til etasje 5», «<kbd>E</kbd> Gå ned trappa», «Gå hjem».
- Kjør `npm run format` før hver commit. Commit aldri `.claude/launch.json` eller `docs/presentasjon/`.

## Review Focus

1. **Flagget av:** `villagePaths(false)` gir akkurat de stiene vi har i dag, og grottearkene er ikke med blant arkene bygda laster. Testes i task 3 og 4.
2. **Gamle lagringer:** `deepest` som mangler, er negativ, en desimal eller en tekst, blir 0. Testes i task 2.
3. **Trykk for å gå i grotta:** en rute fra trykk går aldri gjennom vegg eller stein, og et trykk på en vegg gir ingen rute. Testes i task 3.
4. **Reload i grotta:** spilleren starter i bygda, og `deepest` er bevart. Sjekkes i nettleseren i task 6.
5. **«Gå til» fra grotta:** spilleren kommer hjem først og går så til stedet, uten å bli stående fast. Sjekkes i nettleseren i task 6.
