# Grotta: G2 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kamp begge veier i grotta. Du kan slå og bli truffet, drikke drikker fra Studio, slå steiner og finne materialer, og besvime og våkne hos Brann. Da mister du bare det du fant på turen. Rotte, slim og edderkopp. Grotta står stille når Studio er åpent eller vinduet ikke har fokus. Alt ligger bak `FEATURES.cave`.

**Architecture:**
- Reglene og tallene er rene funksjoner uten Phaser og React:
  - `cave/combat.ts` for skade, skalering, drikker og XP;
  - `cave/brain.ts` for hva et monster gjør i hvert steg;
  - `cave/trip.ts` for funnene på turen.
- `CaveScene` eier kampen, fordi den skjer mange ganger i sekundet. Den eier også livet ditt og skriver `cave: { depth, hp, maxHp }` i `bridge.world`. React skriver ikke lenger `area` eller `cave`; det rydder dobbeltskrivingen fra G1.
- Scenen sender fakta som hendelser: `enemyDefeated`, `found`, `fainted` og `reachedFloor`. React lagrer dem i `Progress` (`xp`, `trip`, `inCave`, `deepest`).
- HUD sender `caveAttack` og `drink` til scenen, og ber den holde seg i ro med `away`.

**Tech Stack:** Phaser 4.2.1, React 19 / Next 16, TypeScript, `node --test` med `sucrase`.

## Global Constraints

- Med `FEATURES.cave` av er bygda nøyaktig som før. `useCombat.ts` og snømonsteret endres ikke.
- **Ingen luke leser noe fra grotta.** Grotta står stille når et panel er åpent (`frozen`), når Studio-panelet er åpent, og når vinduet mister fokus (`blur` og `visibilitychange`). Da beveger ingen monstre seg, ingen tidtakere går, og ingen kan treffe deg.
- **Monstrene blir slått ut, ikke drept.** De forsvinner i en snøsky. Du «besvimer» og «våkner hos Brann».
- Grafikken i spillet er bare Kenney-ark som allerede ligger i repoet. HUD-ikoner tegnes som SVG i `src/components/hud/icons.tsx`, som de som finnes der i dag. Ingen nedlasting og ingen nye npm-avhengigheter.
- Nye felt i `Progress` legges bare til og vaskes i `readProgress`. Livet ditt lagres ikke.
- Høyst 6 monstre på en etasje. Ingen nye objekter per bilde.
- Alle tall under er startverdier (`plan-grotta.md`, del 8). De står som navngitte konstanter i `combat.ts`.
- Norsk tekst i vanlige ord, nøyaktig som skrevet her. Ingen ekstra hjelpelinjer.
- Kjør `npm run format` før hver commit. Commit aldri `.claude/launch.json` eller `docs/presentasjon/`.

  - The values are the table in `plan-grotta.md` del 5, with two exceptions: `rat.hp = 12` and `slime.hp = 18`. They are raised so the «2–5 slag»-test passes, as del 8 says to do.

- Produces in `combat.ts`:
  - The constants:

    | Constant | Value |
    | --- | --- |
    | `PLAYER_MAX_HP` | 10 |
    | `SWING_REACH` | 18 |
    | `SWING_ARC_DEG` | 60 (each side of facing) |
    | `SWING_COOLDOWN_MS` | 350 |
    | `INVULNERABLE_MS` | 1000 |
    | `KNOCK_ENEMY` | 8 |
    | `KNOCK_PLAYER` | 6 |
    | `DRINK_HEAL` | 4 |
    | `MAX_DRINKS` | 3 |
    | `WEAK_MULTIPLIER` | 1.5 |
    | `CHASE_TELL_MS` | 250 |
    | `MIN_WINDUP_MS` | 350 |
    | `AGGRO_RANGE` | 112 |
    | `BITE_START` | 14 |
    | `BITE_RANGE` | 16 |
    | `BITE_REST_MS` | 900 |
    | `CHARGE_TRIGGER` | 96 |
    | `DASH_SPEED` | 150 |
    | `DASH_MAX` | 80 |
    | `DASH_HIT` | 10 |
    | `CHARGE_REST_MS` | 1000 |

  - `type Attack = { damage: number; element: Element | null }`.
  - `type Facing = "left" | "right" | "up" | "down"`.
  - `scaleEnemy(id: EnemyId, depth: number): { hp: number; damage: number; windupMs: number | null }`. It rounds `hp × (1 + 0.12 × (depth − 1))` and `damage × (1 + 0.08 × (depth − 1))`, with damage at least 1. `windupMs` is the first `charge` move's `windupMs × (1 − 0.05 × (depth − 1))`, never under `MIN_WINDUP_MS`, or `null` when the kind has no `charge`.
  - `hitEnemy(attack: Attack | null, id: EnemyId, roll: number): { damage: number; affinity?: "weak" | "immune" }`. `roll` is 0, 1 or 2 (the +0–2 variance). `null` gives `{ damage: 0 }`. Weak gives `Math.round((damage + roll) × 1.5)`, and immune gives 0.
  - `canSwing(lastAt: number | null, now: number): boolean`.
  - `inSwing(from: Point, facing: Facing, target: Point): boolean`: the target is within `SWING_REACH` and within `SWING_ARC_DEG` of the facing direction.
  - `canDrink(drunk: string[], itemId: string, hp: number): "ok" | "again" | "limit" | "full"`. It checks in this order: `full` when `hp >= PLAYER_MAX_HP`, then `again`, then `limit`.
  - `xpFor(id: EnemyId, depth: number): number` = `ENEMIES[id].xp + 2 × (depth − 1)`.
  - `rockDrop(roll: number): MaterialId | null`. `roll` is in [0, 1): under 0.4 gives `"malm"`, under 0.55 gives `"isskar"`, and anything else gives `null`.
- Produces in `brain.ts`:
  - `type Brain = { enemy: EnemyId; x: number; y: number; hp: number; maxHp: number; damage: number; windupMs: number | null; mode: "idle" | "chase" | "tell" | "windup" | "dash" | "rest"; until: number; dir: Point; dashLeft: number }`.
  - `spawnBrain(enemy: EnemyId, at: Point, depth: number): Brain`, which starts in `"idle"`.
  - `stepBrain(b: Brain, player: Point, now: number, dtSec: number, move: (from: Point, dx: number, dy: number) => Point): { brain: Brain; strike: number }`. `strike` is the damage dealt to the player this step, 0 for none. `now` is the scene's own clock in ms.
  - The state machine:
    - `idle` → `chase` once the player is within `AGGRO_RANGE`.
    - `chase` moves toward the player at `speed`.
    - For a kind with `charge`: at distance < `CHARGE_TRIGGER` → `windup` until `now + windupMs`, with `dir` locked toward the player. Then `dash`: move `DASH_SPEED × dt` along `dir` until `DASH_MAX` is used or `move` returns the same point. It strikes once if within `DASH_HIT`. Then `rest` for `CHARGE_REST_MS`.
    - For a kind without `charge`: at distance < `BITE_START` → `tell` for `CHASE_TELL_MS`. Then strike if within `BITE_RANGE`, and go to `rest` for `BITE_REST_MS` either way.
    - `rest` → `chase`.

    - set `invulnerableUntil = clock + INVULNERABLE_MS`;

- [ ] **Step 6: Holding still.**
